# Mohamed Aboushanab — Portfolio

Static site. No build step, no dependencies.

## Deploy on GitHub Pages
1. Push the **contents of this folder** (both `index.html` and `images/`) to a repo.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Live at `https://<username>.github.io/<repo>/`.

## Files
- `index.html` — the site (fonts and scripts embedded).
- `images/slots/` — **required.** The project photos load from here. Keep the folder next to `index.html` or images will not appear.
- `images/*.png` — original uploads, kept for reference only.

Both must be uploaded together.
