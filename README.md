# Mohamed Aboushanab — Portfolio

Static site. No build step, no dependencies.

## Deploy on GitHub Pages
1. Push the contents of this folder to a repo.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/<repo>/`.

## Files
- `index.html` — the entire site. All images, fonts and scripts are embedded; it works offline if you open it directly.
- `images/` — original source images, kept for reference and future edits (not required for the site to run).

## Editing
`index.html` is compiled output — edit the source project and re-export rather than editing it by hand.
